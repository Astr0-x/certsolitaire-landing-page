## What is CertSolitaire?

CertSolitaire turns CompTIA exam prep into a sorting game. It is a gamified, active-recall word-solitaire app for CompTIA A+, Network+, and Security+ (SY0-701).

The core app is free, works offline, and collects no data.

### Features

- Active-recall word-solitaire gameplay for certification terms and concepts
- Custom JSON deck studio — build your own study decks
- AI endless cram mode
- Offline study, no data collection

### Premium decks ($1.99 each)

- Cyber Blue Team & SOC Analyst
- Ports & CLI Drill
- Cloud & Linux Essentials
